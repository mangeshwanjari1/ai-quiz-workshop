# AI Quiz Workshop — Module 1

A simple Streamlit starter application for a one-hour AI quiz agents workshop.

## Run

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Module 1 demonstrates student/teacher interface selection and quiz parameters. It does **not** yet implement authentication, AI, persistence, or email.
